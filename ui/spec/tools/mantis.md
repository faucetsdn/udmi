# 🐛 Tool Specification: Mantis AI Triage Micro-Frontend

This document defines the functional requirements and visual controls for the **Mantis** AI triage and trace analysis tool.

---

## 1. Tool Purpose

**Mantis** is an intelligent debugging tool that collects execution telemetry, chronological event traces, and device payload trees to perform automated AI Root Cause Analysis on test failures.

---

## 2. Layout & Functional Panels

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ Local Toolbar: Device Dropdown | Test Case Dropdown | Playbook | [Run AI Triage]│
├──────────────────────────┬──────────────────────────┬───────────────────────┤
│ Panel 1: Trace Timeline  │ Panel 2: Payload Inspector│ Panel 3: AI RCA Report│
│ ┌──────────────────────┐ │ ┌──────────────────────┐ │ ┌───────────────────┐ │
│ │ 08:31:00 State Msg   │ │ │ {                    │ │ │ # Root Cause      │ │
│ │ 08:31:02 Config Fail │ │ │   "system": { ... }  │ │ │ The failure occurred│ │
│ └──────────────────────┘ │ └──────────────────────┘ │ └───────────────────┘ │
└──────────────────────────┴──────────────────────────┴───────────────────────┘
```

### 2.1 Scenario Configuration Toolbar
- **Target Device Selector**: Dropdown to select target device.
- **Failed Test Selector**: Dropdown listing failed test cases for the selected device.
- **Playbook Selector**: Dropdown choosing triage playbook rules.
- **Run Triage Action Button**: Launches `/api/run_triage`.

### 2.2 Chronological Trace Timeline (Left)
- Vertical timeline displaying sequence of telemetry, state, and config messages exchange leading up to the failure.
- Selecting a trace node updates the Payload Inspector panel.

### 2.3 Payload Inspector Panel (Middle)
- Collapsible JSON tree viewer showing raw MQTT / UDMI payloads for the selected trace event.
- Includes key/value type highlighting and raw copy functionality.

### 2.4 AI Root Cause Report Panel (Right)
- Renders Markdown report generated by AI triage execution (`/api/triage_report`).
- Formatted sections for: *Failure Summary*, *Root Cause Explanation*, *Remediation Steps*, and *Confidence Score*.
