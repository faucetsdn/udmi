# 🎨 Disposable Implementation Presets (`ui/spec/impl/`)

> [!IMPORTANT]
> **DISPOSABLE IMPLEMENTATION PRESETS**  
> The specifications in this directory define **HOW** the current UI presentation layer is laid out and styled (Vanilla JS/CSS v1 layout, Material 3 design tokens, viewport rules, and component CSS rules).  
> 
> **If you throw away the current UI and build a new UI from scratch (e.g. in React, Next.js, Vue, Tailwind, or Desktop Shell), you can DISCARD OR OVERWRITE this directory completely.**  
> 
> Permanent domain capabilities and system requirements stay intact in [`ui/spec/core/`](../core/README.md).

---

| File | Description |
| :--- | :--- |
