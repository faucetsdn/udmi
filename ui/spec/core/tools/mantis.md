# 🐛 Tool Specification: Mantis AI Triage Tool

This document defines the functional capabilities, analytical inputs, and report output requirements for the **Mantis** AI triage and telemetry debugging tool.

---

## 1. Domain Purpose

**Mantis** is an intelligent debugging tool that collects execution telemetry, chronological event sequences, and device payload trees to perform automated AI Root Cause Analysis on test failures.

---

## 2. Functional Capabilities & Capabilities

### 2.1 Scenario Configuration Inputs
- **Target Device Selection**: Selector choosing the target device ID.
- **Failed Test Selection**: Selector listing failed test cases for the selected device.
- **Target Environment Config (`project_spec`)**: Configures target environment string (`[//provider/]project[/namespace][+user]`) to retrieve GCP or MQTT trace logs for AI analysis.
- **Playbook Selection**: Selector choosing triage playbook rules.
- **AI Triage Process Action**: Action control to launch (`Run AI Triage`) or stop active triage analysis (`/api/run_triage`).

### 2.2 Chronological Event Trace Analysis
- Displays timestamped sequence of telemetry, state, and config messages preceding a test failure.
- Selecting a trace node updates the telemetry payload inspection context.

### 2.3 Telemetry Payload Inspector
- Collapsible JSON inspector showing raw MQTT / UDMI telemetry, state, and config payloads for selected trace events.
- Displays value type indicators (strings, numbers, booleans, nulls) and raw payload string copying.

### 2.4 AI Root Cause Analysis Report
- Renders Markdown report generated by AI triage execution (`/api/triage_report`).
- Includes sections for: *Failure Summary*, *Root Cause Explanation*, *Remediation Steps*, and *Confidence Score*.
